🧠 Cómo funciona y limitaciones honestas

  • Usamos Web Speech API del navegador (gratis, sin API keys).
  • El score mide "¿se entendió lo que dijiste?", NO acento nativo perfecto.
  • Si el reconocimiento te confunde "cat" con "cut", es porque tu pronunciación no fue clara para esa palabra → buena señal para practicar.
  • Para acento más fino (B2+), eventualmente integraremos Whisper de OpenAI.
  • Habla cerca del micrófono, en lugar silencioso, a velocidad normal.
